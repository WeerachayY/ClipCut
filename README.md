# ClipCut

PWA สำหรับตัดช่วงที่ไม่ต้องการออกจากวิดีโอ เช่น ช่วงรอเริ่ม ช่วงพัก หรือท้ายคลิปที่ลืมหยุดบันทึก
เหมาะกับวิดีโอที่มีคนพูดเป็นหลัก เช่น ประชุม อบรม สัมมนา คลาสเรียน หรือสัมภาษณ์
แอปใช้ transcript (ถ้ามี) ร่วมกับการวัดเสียงเงียบ เพื่อเสนอช่วงที่ควรตัด แล้วให้คนฟังรอยต่อก่อนยืนยัน

- **ประมวลผลในเครื่องทั้งหมด** วิดีโอและ transcript ไม่ถูกอัปโหลดไปไหน ไม่ใช้ AI
- **ตัดแบบไม่ encode ใหม่** คุณภาพเท่าต้นฉบับ เร็วราว 1 นาทีต่อวิดีโอ 500 MB (ไม่ขึ้นกับความยาว)
- **ต่อหลายไฟล์** ที่บันทึกต่อกันเป็นไฟล์เดียว และ **แบ่งไฟล์เดียวเป็นหลายตอน** ได้ในขั้นตอนเดียวกัน
- **แต่งแบบ CapCut**: ข้อความ hook, โลโก้, วิดีโอซ้อน, เพลงประกอบที่เบาลงเองตอนมีคนพูด, ปรับความเร็วเป็นช่วง ๆ ด้วยเส้นโค้ง
  แล้วเรนเดอร์ด้วยการ์ดจอ (ไม่ใช้ AI เหมือนเดิม)
- **บีบอัดให้เล็กลง** แบบ HandBrake (H.264) เป็นตัวเลือก (ทดลอง ช้ากว่ามาก)
- ใช้ได้ดีที่สุดบน **Edge หรือ Chrome บนคอมพิวเตอร์** (เปิดทั้งโฟลเดอร์และบันทึกผลกลับลงโฟลเดอร์ได้)

## วิธีใช้

รองรับวิดีโอ (.mp4, .mov) และ **ไฟล์เสียง (.mp3, .m4a, .wav)** งานหนึ่งเป็นวิดีโอหรือเสียงอย่างใดอย่างหนึ่ง

หน้าแรกคือ **รายการงาน** — งานหนึ่งงานคือวิดีโอหรือไฟล์เสียงชุดหนึ่งกับจุดตัดทั้งหมดที่ทำไว้ บันทึกอัตโนมัติตลอด

- **งานใหม่** — กด “เปิดโฟลเดอร์” หรือ “เลือกไฟล์” หรือลากโฟลเดอร์/ไฟล์มาวางที่หน้ารายการงาน
  ชื่องานตั้งให้จากชื่อโฟลเดอร์หรือชื่อไฟล์แรก ถ้าเปิดโฟลเดอร์หรือไฟล์ชุดเดิมซ้ำ แอปจะเปิดงานเดิมให้แทนการสร้างซ้ำ
- **เปิดงานเก่า** — คลิกการ์ดงาน Edge/Chrome จะขออนุญาตเข้าถึงโฟลเดอร์หรือไฟล์ครั้งเดียว (เลือก “อนุญาตทุกครั้ง” ได้)
  แล้วเปิดต่อจากขั้นที่ทำค้างไว้ browser อื่นจะให้เลือกไฟล์เดิมอีกครั้ง ถ้าไฟล์ถูกย้าย การ์ดจะขึ้น “หาไฟล์ไม่เจอ” กด “ชี้ไฟล์ใหม่”
- **เปลี่ยนชื่องาน** — คลิกชื่องานบนแถบด้านบนขณะทำงาน หรือดับเบิลคลิกชื่อบนการ์ด (หรือเมนู ⋯ → เปลี่ยนชื่อ)
- เมนู ⋯ บนการ์ดมี ทำสำเนา, ดาวน์โหลดไฟล์งาน (สำรองหรือย้ายเครื่อง) และ ลบออกจากรายการ
  (ลบแค่จากรายการ ไม่ลบวิดีโอหรือไฟล์ที่ส่งออก)

ในงานหนึ่งมี 4 ขั้น:

1. **ไฟล์** — เช็คลำดับวิดีโอ (เลื่อนขึ้นลงได้) และ transcript ที่ใช้ ปรับเกณฑ์ได้ใน “ตั้งค่าการหาจุดตัด”
   แล้วกด “หาจุดตัด” (ครั้งแรกจะโหลดตัวประมวลผลวิดีโอราว 32 MB และวิเคราะห์เสียงราว 1 นาทีต่อชั่วโมง)
2. **ตรวจจุดตัด** — ทำงานแบบ “ผ่าแล้วเลือกชิ้น” เหมือนเครื่องมือ Razor/Blade ในโปรแกรมตัดต่อ
   - กด **มาร์กจุดตัด** (C) เพื่อผ่าวิดีโอที่ตำแหน่งเล่น จุดตัดแต่ละจุดแบ่งวิดีโอเป็นชิ้น
   - **คลิกชิ้น** บน timeline แล้วกด “ทิ้งชิ้นนี้” (หรือดับเบิลคลิกชิ้น) ชิ้นที่ทิ้งจะเป็นลายทางแดง
   - **คลิกที่หัวจุดตัด** เพื่อ “ต่อกลับ” (ชิ้นสองข้างรวมกันและถูกเก็บไว้เสมอ), “แยกเป็นไฟล์ใหม่ตรงนี้”, หรือขยับ ±1 วิ
     **ลากหัวจุดตัด** เพื่อขยับ (ดูดเข้าหาตำแหน่งเล่นเมื่อลากเข้าใกล้)
   - ช่วงที่แอปหาให้จะมาเป็นชิ้นที่ “แนะนำให้ทิ้ง” (กรอบแดง) หรือ “ควรเช็ค” (กรอบส้ม) กดทิ้งหรือเก็บทีละชิ้น
     หรือ “ทิ้งทุกชิ้นที่แนะนำ”
   - กด **ฟังรอยต่อ** เพื่อฟัง 5 วินาทีก่อนชิ้นที่ทิ้ง แล้วกระโดดไปฟัง 5 วินาทีหลังชิ้นนั้น (เหมือนไฟล์ผลลัพธ์)
   - เส้นประจาง ๆ ในชิ้นที่ทิ้งคือจุดที่แบบไม่บีบอัดจะกลับมาเล่นจริง (keyframe) แบบบีบอัดตัดตรงจุดเป๊ะ
   - แท็บ **Transcript และหมุดเวลา**: ถ้าเวลาใน transcript ไม่ตรงกับเสียง ให้เล่นวิดีโอแล้วกดหมุดของบรรทัดนั้น
     ตอนได้ยินประโยคเริ่ม ปักได้หลายจุด (โหมด “ค่อย ๆ ไล่เวลา” สำหรับเวลาคลาดสะสม,
     “กระโดดที่หมุด” สำหรับการบันทึกที่หยุดแล้วเริ่มใหม่) หรือกด “หาหมุดจากจุดที่เสียงกลับมา”
   - ติ๊ก “เล่นแบบผลลัพธ์” เพื่อดูวิดีโอโดยข้ามช่วงที่ตัดแล้ว
   - **ขั้นของการเลื่อน** เลือกข้างตัวเลขเวลา: เฟรมภาพ / 10 ms / 1 ms (ปุ่ม ← → และการขยับจุดตัดใช้ขั้นนี้)
     ปุ่ม `1` / `2` กระโดดไปจุดที่เสียงเริ่มหรือหยุด เหมาะกับการตัดที่ตัดสินกันที่เสียงพูด
   - **แทร็กภาพย่อและคลื่นเสียง** บน timeline แบบ CapCut ช่วงพักและช่วงเงียบเห็นได้ทันที ซ่อน/แสดงได้ด้วยปุ่ม “ภาพ” “เสียง”
     (คลื่นเสียงวัดพร้อมเสียงเงียบตอนกด “หาจุดตัด” และเก็บไว้กับงาน)
   - **ตัดจาก transcript**: แท็บ Transcript คลิกบรรทัด (ลากหรือ Shift+คลิกเพื่อเลือกหลายบรรทัด) แล้วกด Delete
     แอปผ่าที่จุดเงียบใกล้ขอบบรรทัดให้เอง บรรทัดที่ทิ้งแล้วจะขีดฆ่า เลือกแล้วกด “เก็บกลับ” ได้
3. **แต่ง** (ข้ามได้) — หน้าตาแบบ CapCut: ภาพตัวอย่างของผลลัพธ์ด้านบน แผงปรับค่าด้านขวา timeline แยกแทร็กด้านล่าง
   - **ข้อความ** — กด “ข้อความ” แล้วเลือกแบบ (hook ตัวใหญ่, ป้ายเหลือง, แถบแดง, พิมพ์ทีละตัว, ชื่อผู้พูด, ธรรมดา)
     พิมพ์ในแผงขวา ลากบนภาพเพื่อย้าย ลากมุมเพื่อย่อขยาย ปรับฟอนต์ สี ขอบ พื้นหลัง และการเคลื่อนไหวได้
   - **รูป / โลโก้** และ **วิดีโอซ้อน** — วางมุมขวาบน (โลโก้) มุมขวาล่าง (ภาพในภาพ) หรือเต็มจอ ปรับความทึบ ค่อย ๆ ปรากฏ/หาย
   - **เพลง / เสียง** — เพลงประกอบ **เบาลงเองเมื่อมีคนพูด** (เลือกระดับ ไม่ลด/น้อย/กลาง/มาก) ค่อย ๆ ดัง/เบา ปรับความดัง
     ลากขอบซ้ายของคลิปเพื่อข้ามช่วงต้นเพลง
   - **ความเร็ว** — คลิกชิ้นบนแทร็กหลัก (แถบภาพและคลื่นเสียง) ตั้งความเร็วคงที่ 0.1×–10× หรือ **เส้นโค้ง** แบบ CapCut
     (มอนทาจ, ฮีโร่, กระสุน, กระโดด, แฟลชเข้า/ออก) แล้วลากจุดบนกราฟเพื่อปรับเอง เสียงคนพูดไม่เพี้ยน
   - ทุกอย่างวางบนเวลาของผลลัพธ์ ซ้อนกันได้หลายแทร็ก (แทร็กบนสุดอยู่หน้าสุด) ลากย้าย ตัดแต่งขอบ แยก ทำซ้ำ ลบ ย้อนกลับได้
   - ลากไฟล์รูป วิดีโอ หรือเพลงมาวางบน timeline ก็ได้ ไฟล์เหล่านี้เก็บไว้ใน browser กับงาน
4. **ส่งออก** — มีสองโหมด: **ตัดช่วงทิ้ง** (ได้ไฟล์ที่ตัดชิ้นที่ทิ้งออกแล้ว) หรือ **เลือกและเรียงชิ้น**
   (ทุกชิ้นที่ผ่าไว้เป็นรายการ ตั้งชื่อ ติ๊กเลือก ลากเรียงลำดับ แล้วส่งออกแยกชิ้นละไฟล์หรือต่อเป็นไฟล์เดียวตามลำดับใหม่)
   ไฟล์เสียงเลือกได้ระหว่าง “ไม่เข้ารหัสใหม่” (จุดตัดคลาดได้ไม่เกิน 0.026 วินาที) กับ “ตัดตรงจุดเป๊ะ” (เข้ารหัสใหม่)
   จากนั้นเลือก “ไม่บีบอัด” (แนะนำ) หรือ “บีบอัดไฟล์ให้เล็กลง” แล้วกดส่งออก
   ถ้าแต่งภาพหรือความเร็วไว้ แอปจะเลือก **“เรนเดอร์ด้วยการ์ดจอ”** ให้ (แบบไม่บีบอัดยังใช้ได้ถ้าแต่งแค่เสียง)
   และมี **“ส่งออกเฉพาะเสียง”** (.m4a / .mp3 / .wav) สำหรับ podcast หรือส่งให้คนฟัง
   ไฟล์จะถูกบันทึกในโฟลเดอร์ `output/` ข้างไฟล์ต้นฉบับ พร้อมไฟล์ที่ได้เพิ่ม (เลือกได้): `_สรุปการตัด.txt`
   และ **คำบรรยาย `.srt`** ที่เวลาตรงกับไฟล์ที่ตัดแล้ว (ชื่อเดียวกับวิดีโอ player ส่วนใหญ่เปิดให้เอง)

รายการงานเก็บใน browser เครื่องนี้ (IndexedDB) ไม่คัดลอกวิดีโอ งานที่เปิดจากโฟลเดอร์จะมี `clipcut.project.json`
ในโฟลเดอร์ด้วย ถ้าล้างข้อมูล browser หรือย้ายไปเครื่องอื่น เปิดโฟลเดอร์เดิมก็ทำต่อได้

### ปุ่มลัด (หน้าตรวจจุดตัด)

ตั้งให้เหมือน CapCut เท่าที่มีคำสั่งเดียวกัน กด `?` ในแอปเพื่อดูตารางนี้ และเอาเมาส์ชี้ปุ่มใดก็ได้จะเห็นปุ่มลัดของมัน

| ปุ่ม | ทำอะไร | เทียบ CapCut |
|---|---|---|
| Space | เล่น / หยุด | เหมือนกัน |
| ← / → | ถอย / ไปข้างหน้า 1 ขั้น (เฟรมภาพ, 10 ms หรือ 1 ms ตามที่เลือก) | ทีละเฟรม |
| 1 / 2 | ไปขอบเสียงก่อนหน้า / ถัดไป | — |
| Shift + ← / → | ถอย / ไปข้างหน้า 1 วินาที | CapCut ขยับ 5 เฟรม |
| Ctrl + ← / → | ถอย / ไปข้างหน้า 10 วินาที | — |
| Home / End | ไปต้น / ท้ายวิดีโอ | เหมือนกัน |
| ↑ / ↓ | ไปจุดตัดก่อนหน้า / ถัดไป | เหมือนกัน (edit point) |
| K / L | หยุด / เล่น (กด L ซ้ำเพื่อเร่ง) | เหมือนกัน (ยังไม่มี J เล่นถอยหลัง) |
| C, B หรือ Ctrl + B | มาร์กจุดตัดที่ตำแหน่งเล่น | Ctrl + B |
| Q / W | ทิ้งส่วนก่อน / หลังตำแหน่งเล่นในชิ้นนั้น | เหมือนกัน |
| Delete / Backspace | ทิ้ง/เก็บชิ้นที่เลือก หรือต่อกลับจุดตัดที่เลือก | Delete = ลบคลิป |
| Delete (แท็บ Transcript) | ทิ้งช่วงของบรรทัดที่เลือก | แก้วิดีโอด้วยข้อความ |
| Ctrl + Z / Ctrl + Shift + Z | ย้อนกลับ / ทำซ้ำ | เหมือนกัน |
| Ctrl + = / Ctrl + − / Ctrl + 0 | ซูม timeline เข้า / ออก / พอดีจอ (หรือ Ctrl + ล้อเมาส์) | เหมือนกัน |
| , / . | ขยับจุดตัดที่เลือก 1 เฟรม (กด Shift = 1 วินาที) | — |
| A / R | ทิ้ง / เก็บ ชิ้นที่เลือก | — |
| S | แยกเป็นไฟล์ใหม่ที่จุดตัด | — |
| P | ฟังรอยต่อ | — |
| Shift + ↑ / ↓ | ชิ้นที่ทิ้งหรือแนะนำ ก่อนหน้า / ถัดไป | — |
| [ / ] | ย้ายขอบเริ่ม / จบของชิ้นมาที่ตำแหน่งเล่น | — |
| Esc | ยกเลิกการเลือก | — |

เวลาในหน้าตรวจจุดตัดแสดงแบบ `ชั่วโมง:นาที:วินาที:เฟรม` ตามอัตราเฟรมของวิดีโอ และจุดตัดลงตรงเฟรมเสมอ

## รูปแบบไฟล์ที่รองรับ

| ประเภท | รูปแบบ |
|---|---|
| วิดีโอ | .mp4 / .m4v / .mov ที่ browser เล่นได้ (เช่น H.264 + AAC ซึ่งเป็นค่าปกติของโปรแกรมบันทึกส่วนใหญ่) |
| Transcript | Word (.docx) หรือ .txt ที่เขียนบรรทัดละ `[00:01:34] ชื่อ: ข้อความ` (รูปแบบที่ bot จดบันทึกหลายตัวใช้) · คำบรรยาย .vtt / .srt (เช่น จาก Teams, Zoom, YouTube) |

ไม่มี transcript ก็ใช้ได้ แอปจะเสนอเฉพาะช่วงที่เสียงเงียบนาน

## ข้อจำกัดที่ควรรู้

- **แบบไม่บีบอัด จุดตัดถูกปรับตาม keyframe** แอปจะเลื่อนจุดที่วิดีโอกลับมาเล่นให้ *เร็วขึ้น* ไปยัง keyframe ก่อนหน้า
  (ปกติ 1–4 วินาที) จึงอาจเหลือส่วนที่ทิ้งติดมานิดหน่อย แต่ไม่ทำให้เนื้อหาหาย และชิ้นที่สั้นกว่าระยะ keyframe จะตัดไม่ได้
  แอปแสดงจุดจริงให้ดูทุกชิ้น ถ้าต้องการตัดเป๊ะให้ใช้แบบบีบอัด
- **ที่รอยต่ออาจมีภาพกระตุก 1–2 เฟรม** ถ้าวิดีโอใช้ B-frame เป็นข้อจำกัดของการตัดแบบไม่ encode ใหม่
- **ไฟล์ผลลัพธ์แต่ละไฟล์ต้องเล็กกว่าราว 1.9 GB** (เพดานหน่วยความจำของ browser) ถ้าใหญ่กว่านั้นให้เพิ่มจุดแบ่งไฟล์
  วิดีโอที่บันทึกการพูดหรือหน้าจอมักเล็กกว่านี้มาก
- **การต่อหลายไฟล์แบบไม่บีบอัด** ต้องเป็นไฟล์ที่บันทึกด้วยการตั้งค่าเดียวกัน แอปตรวจและเตือนให้
- **แบบบีบอัด** ตัดตรงจุดเป๊ะ แต่ใช้ CPU ใน browser ช้าราวเวลาจริงหรือมากกว่า เหมาะกับวิดีโอสั้น หรือปล่อยทิ้งไว้
- **เรนเดอร์ด้วยการ์ดจอ** ต้องใช้ Edge หรือ Chrome รุ่นใหม่ (WebCodecs) browser เลือกเองว่าใช้การ์ดจอหรือ CPU
  ความเร็วจึงขึ้นกับเครื่อง (บนเครื่องที่ไม่มีการ์ดจอช้ากว่าเวลาจริง) ระหว่างเรนเดอร์ควรเปิดแท็บนี้ไว้
  งานที่ไม่ได้เปิดจากโฟลเดอร์ ผลลัพธ์เก็บในหน่วยความจำก่อนดาวน์โหลด จึงยังมีเพดานราว 1.9 GB ต่อไฟล์
- **เสียงในภาพตัวอย่างของหน้าแต่ง** ดังได้สูงสุด 100% และการลดเสียงเพลงเป็นค่าประมาณ ไฟล์ที่ส่งออกใช้ค่าจริงทั้งหมด
- **เพลง รูป และวิดีโอที่ใส่ในหน้าแต่ง** เก็บใน browser เครื่องนี้ (ไม่อยู่ใน `clipcut.project.json`)
  เปิดงานบนเครื่องอื่นต้องเลือกไฟล์เหล่านั้นอีกครั้ง (แผงขวาจะมีปุ่มให้) ไฟล์ละไม่เกิน 600 MB

## Deploy ขึ้น GitHub Pages

ไม่มีขั้นตอน build ไฟล์ใน repo คือเว็บที่ใช้จริง

1. สร้าง repo ใหม่บน GitHub แล้ว push ทั้งโฟลเดอร์นี้ขึ้นไป
   ```bash
   git init && git add . && git commit -m "ClipCut"
   git branch -M main
   git remote add origin https://github.com/<user>/clipcut.git
   git push -u origin main
   ```
   (ไฟล์ `vendor/core/ffmpeg-core.wasm` ขนาด ~32 MB push ได้ตามปกติ ไม่ต้องใช้ Git LFS)
2. ใน repo ไปที่ **Settings → Pages** เลือก Source = *Deploy from a branch*, Branch = `main`, โฟลเดอร์ `/ (root)`
3. รอสักครู่ แล้วเปิด `https://<user>.github.io/clipcut/`
4. ใน Edge/Chrome กดไอคอนติดตั้งในแถบที่อยู่ เพื่อใช้เป็นแอปและใช้ offline ได้

เมื่อแก้โค้ดแล้ว push ใหม่ รอ GitHub Pages อัปเดตราว 1–2 นาที แล้วเปิดหน้าใหม่ก็ได้เวอร์ชันใหม่ทันที
(แอปโหลดไฟล์จาก server ก่อนเสมอ ใช้ไฟล์ที่เก็บไว้ในเครื่องเฉพาะตอน offline)

**ออกเวอร์ชันใหม่:** เปลี่ยนเลขให้ตรงกันใน `js/version.js`, `package.json` และ `VERSION` ใน `sw.js`
(test จะเตือนถ้าไม่ตรง) แล้วเขียนสิ่งที่เปลี่ยนไว้ใน `CHANGELOG.md` เลขเวอร์ชันแสดงข้างโลโก้ในแอป

### ทดลองบนเครื่องตัวเอง

ต้องเปิดผ่าน http server (เปิดไฟล์ index.html ตรง ๆ ไม่ได้ เพราะใช้ ES modules และ service worker)

```bash
python3 -m http.server 8080
# แล้วเปิด http://localhost:8080
```

## โครงสร้างโค้ด

```
index.html, sw.js, manifest.webmanifest   หน้าเว็บ, service worker (offline), ข้อมูลแอป
css/app.css                               หน้าตาทั้งหมด (โทนสีอยู่บนสุด รองรับ dark mode)
js/main.js                                ตัวควบคุมแอป: โหลดไฟล์, วิเคราะห์, บันทึกงาน, สลับหน้า
js/version.js                             เลขเวอร์ชันของแอป
js/core/                                  ตรรกะล้วน ไม่แตะ DOM ทดสอบได้ด้วย Node
  timeline.js    ต่อหลายไฟล์เป็น timeline เดียว + หา keyframe
  timemap.js     หมุดเวลา transcript ↔ วิดีโอ (linear / step)
  suggest.js     รวมผลจากตัวหาจุดตัดหลายตัวเป็นข้อเสนอพร้อมระดับความมั่นใจ
  analysis.js    เรียกตัวหาจุดตัดทุกตัว + เสนอหมุดอัตโนมัติ
  plan.js        แปลงการตัดสินใจเป็นแผนส่งออก (concat inpoint/outpoint)
  cuts.js        จุดตัดและชิ้น: มาร์ก, ต่อกลับ, ขยับ, แยกไฟล์, ทิ้ง/เก็บ, รับข้อเสนออัตโนมัติ
  registry.js    ทะเบียนปลั๊กอิน (ดู docs/EXTENDING.md)
  store.js       state ของแอป + บันทึก/โหลดไฟล์งาน
  arrange.js     โหมดเลือกและเรียงชิ้น: รายการคลิป ลำดับ ชื่อ
  program.js     เวลาของผลลัพธ์: แผนส่งออก + ความเร็วของแต่ละชิ้น, แปลงเวลาไป-กลับกับต้นฉบับ
  speed.js       ความเร็วคงที่และเส้นโค้งแบบ CapCut, ความยาวหลังปรับ
  compose.js     สิ่งที่แต่ง: แทร็ก คลิป (ข้อความ ภาพ วิดีโอ เสียง) แบบข้อความสำเร็จรูป ระดับการลดเสียงเพลง
  audiograph.js  เสียงของแต่ละไฟล์ผลลัพธ์เป็นคำสั่ง ffmpeg เดียว (ความเร็ว, ผสมเพลง, ducking)
  jobs.js        งาน: ตั้งชื่อ, ตัวเลขบนการ์ด, สถานะ, จับคู่ไฟล์เมื่อชี้ไฟล์ใหม่
  textedit.js    บรรทัด transcript เป็นช่วงเวลา, หาจุดเงียบใกล้ขอบ, สถานะบรรทัด (ทิ้ง/เก็บ)
  captions.js    คำบรรยายบนเวลาของไฟล์ผลลัพธ์ + เขียน .srt
js/plugins/                               ฟีเจอร์ที่ถอด-ใส่ได้ ลงทะเบียนใน plugins/index.js
  transcript/    ตัวอ่าน transcript (.docx, .vtt/.srt, .txt)
  detectors/     ตัวหาจุดตัด (ช่องว่างใน transcript, คำบอกเบรก, เสียงเงียบ)
  export/        วิธีส่งออก (วิดีโอ: ไม่บีบอัด, การ์ดจอ, บีบอัด H.264, เฉพาะเสียง · เสียง: ไม่เข้ารหัสใหม่, ตัดตรงจุดเป๊ะ)
  extras/        ไฟล์ที่ได้เพิ่มตอนส่งออก (สรุปการตัด, คำบรรยาย .srt)
  layers/        ข้อมูลที่วัดจากสื่อครั้งเดียวแล้วเก็บกับงาน (คลื่นเสียง)
  tracks/        แทร็กบน timeline (ภาพย่อ, คลื่นเสียง)
js/media/                                 งานที่แตะวิดีโอ: ffmpeg.wasm, อ่าน keyframe, วิเคราะห์เสียง, ส่งออก
js/render/                                วาดและเรนเดอร์สิ่งที่แต่ง: ข้อความบน canvas, เฟรมหนึ่งเฟรม (ใช้ทั้งภาพตัวอย่างและตอนส่งออก),
                                          ไฟล์ที่ใส่เพิ่ม (assets.js), เข้ารหัสด้วยการ์ดจอ (gpu.js, Mediabunny + WebCodecs), ส่งออก (export-program.js)
js/io/                                    เปิดโฟลเดอร์/ไฟล์, อ่าน zip (.docx), บันทึกไฟล์, รายการงาน (jobs-db.js)
js/ui/                                    หน้ารายการงาน, หน้าจอทั้ง 4 ขั้น, timeline, player (หน้าแต่ง: screen-compose.js,
                                          program-player.js, compose-timeline.js, speed-editor.js)
icons/                                    logo-source.svg (โลโก้ต้นฉบับ มีตัวหนังสือ), icon.svg (ไอคอนแอป), favicon.svg (แบบเรียบสำหรับขนาดเล็ก),
                                          PNG สำหรับติดตั้งแอป — สร้างใหม่ด้วย scripts/make-icons.py
vendor/                                   ffmpeg.wasm, Mediabunny และฟอนต์ (ดู vendor/README.md)
tests/                                    ทดสอบด้วย `node --test tests/*.test.mjs`
```

## เพิ่มฟีเจอร์

ฟีเจอร์ส่วนใหญ่เพิ่มได้ด้วยไฟล์เดียว + บรรทัดเดียวใน `js/plugins/index.js`
ดูคู่มือและตัวอย่างใน [docs/EXTENDING.md](docs/EXTENDING.md) เช่น

- วิธีส่งออกแบบใหม่ (ปรับเสียงให้ดังเท่ากัน, แปลงเป็นเสียงอย่างเดียว .m4a, ใส่ chapter)
- ตัวหาจุดตัดแบบใหม่ (จอค้างหน้าสไลด์ “Break”, ช่วงที่ภาพนิ่งนาน)
- ตัวอ่าน transcript รูปแบบอื่น

## ทดสอบ

```bash
node --test tests/*.test.mjs
```

- `tests/core.test.mjs` ทดสอบตรรกะทั้งหมด (timeline, หมุดเวลา, แผนตัด, ตัวอ่าน transcript, การรวมข้อเสนอ)
- `tests/ffmpeg-native.test.mjs` รันคำสั่ง ffmpeg แบบเดียวกับที่แอปสร้าง กับ ffmpeg บนเครื่อง แล้วตรวจความยาวไฟล์ผลลัพธ์
  (ข้ามอัตโนมัติถ้าไม่มี ffmpeg)
